## <img src="https://api.iconify.design/lucide:shield-check.svg?color=%231E90FF&width=28&height=28" valign="middle"/> Open Source Philosophy

</div>

VNDXS HUB is **fully open source**. Every line of code is visible, auditable, and available for learning.

**You are free to:**
- Study the code and learn from it
- Fork and modify it for personal use
- Build your own hub on top of it

**You are NOT allowed to:**
- Claim you built this from scratch
- Remove or hide credit to **VNDXS HUB** and its developer **VNDXS**
- If you fork this project, you **must state clearly** that your project was derived from VNDXS HUB

> *"I received this project and took inspiration from VNDXS HUB by VNDXS — not the other way around."*  
> This is the only acceptable way to credit a fork.

## <img src="https://api.iconify.design/lucide:folder-open.svg?color=%231E90FF&width=28&height=28" valign="middle"/> Project Structure

</div>

```
VNDXS-HUB/
│
├── Loader.luau                   ← Entry point — auto-detects game
│
├── Components/
│   ├── Environment.luau          ← Executor capability testing
│   ├── Interface.luau            ← UI library + forced theme
│   ├── InfoTab.luau              ← Info tab
│   ├── SettingsTab.luau          ← Settings + Privacy
│   ├── CreditsTab.luau           ← Credits tab with logo
│   ├── Analytics.luau            ← Opt-in only analytics
│   └── AdonisBypass.luau         ← Adonis admin bypass
│
├── Games/
│   ├── Doors/                    ← DOORS support
│   ├── OneShot/                  ← One Shot combat features
│   └── Universal/                ← General mode fallback
│
└── Scripts/
    └── DeathFarm.luau
```
